\chapter{ผลการทดลอง}

\section{Dataset Validation}

หลักฐานที่มีอยู่ในปัจจุบันสนับสนุนว่า dataset มีการแยกเชิงสถิติระหว่าง normal และ anomaly ใน feature ที่เกี่ยวข้องกับ volatility และ return dynamics อย่างไรก็ตามผลส่วนนี้สนับสนุนความเหมาะสมของ dataset เท่านั้น ไม่ใช่หลักฐานว่าแบบจำลองที่นำเสนอเหนือกว่า baseline

\section{Score-Change Dynamic Threshold}

ผลการทดลองเดิมแสดงว่า score-change dynamic threshold สามารถให้ precision สูง แต่ sensitivity ยังต่ำ ดังนั้นควรตีความเป็นกฎแจ้งเตือนแบบ conservative alert กล่าวคือ เมื่อระบบ flag มักมีความน่าเชื่อถือสูง แต่ยังพลาด anomaly windows จำนวนมาก

\section{Baseline Comparison}

ส่วนนี้ยังต้องเติมหลังจากมีการทดลอง baseline ที่ครบถ้วน เช่น vanilla Anomaly Transformer, LSTM/GRU autoencoder, forecasting-error baseline และ statistical rolling volatility/z-score baseline ภายใต้ split และ tuning budget เดียวกัน

\section{Statistical Testing}

ส่วนนี้ยังต้องเติมหลังจากมี repeated runs หลาย seed เพื่อรายงาน confidence interval และ significance test อย่างเหมาะสม
