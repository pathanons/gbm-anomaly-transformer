\chapter{อภิปรายผล}

ผลลัพธ์ปัจจุบันชี้ว่า GBM-aware formulation เป็นทิศทางที่สมเหตุสมผล เนื่องจาก anomaly signal ในข้อมูลการเงินเกี่ยวข้องกับ volatility และ distributional behavior อย่างเด่นชัด อย่างไรก็ตาม หลักฐานที่มีอยู่ยังไม่เพียงพอสำหรับการสรุปว่าแบบจำลองมีประสิทธิภาพเหนือกว่า baseline หรือสามารถเตือนล่วงหน้าได้ดีกว่าวิธีอื่น

\section{ข้อจำกัด}

\begin{itemize}
  \item ยังไม่มี baseline comparison ที่ครบถ้วนสำหรับ GBM formulation ปัจจุบัน
  \item ยังไม่มี multi-seed evaluation พร้อม confidence interval
  \item ยังไม่มี lead-time analysis สำหรับ early warning
  \item ยังไม่มี explanation faithfulness หรือ stability test
\end{itemize}
