\begin{abstract}
Financial anomaly detection requires models that capture temporal dependencies while remaining aligned with the statistical structure of asset returns. This paper proposes a GBM-aware Transformer framework that combines learned window representations, reconstruction-based modeling, and GBM-implied return distribution consistency. The framework evaluates anomalies through a composite score derived from reconstruction error, distributional likelihood, and divergence between observed and predicted return behavior. We follow a leakage-aware train/validation/test protocol in which validation data are used only for thresholding, hyperparameter tuning, and model selection. Current results support the proposed formulation as a methodological direction; claims of baseline superiority require multi-seed baseline comparisons and statistical significance testing.
\end{abstract}
