# Goal and Aim

## Goal
Develop an interpretable anomaly detection framework for U.S. large-cap stocks that can warn earlier than standard methods and explain why the warning was triggered.

## Aim
1. Detect financial anomalies in daily U.S. equity data.
2. Improve early warning lead time before anomaly events.
3. Explain anomalies at both the feature level and the stock-relation level.
4. Support analysis across multiple market regimes.
5. Produce a paper suitable for IEEE-style AI/ML publication.

## Research Intent
- Use Anomaly Transformer as the backbone.
- Extend it for regime awareness.
- Model temporal patterns at multiple scales.
- Capture cross-sectional stock relations.
- Produce explanations that are useful to analysts and regulators.

## Operational Definition of Success
A successful result should satisfy all of the following:
- Better early-warning recall within the event window.
- Competitive detection accuracy against baselines.
- Meaningful explanations tied to financial variables and stock interactions.
- Stable performance in different market regimes.

## Core Output
The final paper should claim that the model is not only a detector, but also a financial explanation system for market anomalies.
